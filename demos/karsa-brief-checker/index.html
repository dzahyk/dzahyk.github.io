This page runs Karsa's actual requirement extractor (Python, demo-rules-1.2) inside your browser. Every value it finds comes with the exact words it was read from. If it can't point to the words, the value stays missing.

Read this before trusting the output.
  • It is a rule-based parser, not a language model. On 50 briefs it had never seen, it got every field right in 21 of 50 (42%, 95% CI 29–56%), below the 70% release gate. It caught only 1 of 6 new prompt-injection phrasings. The full evaluation is summarised in the Karsa case study.
  • In the product, every value here is only a draft until an analyst confirms it, and brief text can never approve anything.
  • Your text stays in this browser tab. The examples are synthetic; please don't paste confidential briefs.
